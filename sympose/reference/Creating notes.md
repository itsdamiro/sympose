# Creating notes

## Can a persona create a note?

She can propose one, never make one. A new note she proposes is a draft: no file exists in your vault until you accept it. Nothing she does reaches your vault by itself, in any mode.

Ask her, for example "make a note for my reading list". She writes the note and tells you in one sentence what it is.

## Where do I find a note she proposed?

In the Drafts group at the top of the notes list. A new note is listed there, marked new, in the folder it will be made in: the Inbox unless a folder was named. Choose it to read it. It opens in the editor with a bar above it that says it is not in your vault yet, with Decline and Accept.

You can change the draft's text before you accept. What you change is kept with the draft, not in your vault.

## Where is the note saved when I accept it?

The file is saved in your vault with the text as it is now, and opened, in the folder you asked for or else in a folder called Inbox. The file takes the note's title. If a note with that title is already there, Sympose adds a number, such as Plan (2), and never replaces your note.

Decline forgets the draft and creates nothing.

## Which folder is the note saved in, and can I choose a subfolder?

Yes, you can choose any folder or subfolder. Tell her where, for example "make it in Projects/Sympose". The folder is made too if it is not there yet. If you chose none, the note goes to Inbox.

## Where does a new note go if I do not choose a folder?

It goes to a folder called Inbox, inside her main folder. Sympose makes the folder the first time you accept a note there. Move the note out of it whenever you like.

## Can she put it in a folder I did not mention, or use another title?

She picks a folder only when you asked for one; otherwise the note goes to Inbox. The title is the file's title: to use another, rename the note after you accept, from its row's menu.

## Why can't I see the note I asked her to create?

Look in the Drafts group of the folder it was proposed for, the Inbox unless you named one; a new note is listed only there. If it is not there, she may not have proposed one: say "please create it", and check that her reply says she proposed a note. A persona in plan mode only talks and proposes nothing.

## What happens if I ask her for the same note twice?

She does not make a second draft. If a draft with the same name in the same folder, or the same words, is still waiting under Drafts, she says it is already there: accept or decline it first, then ask again.
